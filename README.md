# Simulación de conjuntos

Aplicación interactiva para aprender teoría de conjuntos mediante diagramas de Venn y ejercicios.

## Abrir la aplicación

**Sitio publicado:** https://simulacion-conjunto.netlify.app/

## Funcionalidades

- **Construir:** mueve los elementos entre los conjuntos A y B y verifica su ubicación según las reglas elegidas.
- **Descubrir:** explora un conjunto oculto y trata de identificar la regla que lo define.
- **Reto:** practica operaciones entre conjuntos como intersección, unión, diferencia y complemento.

## Tecnologías

HTML, CSS y JavaScript. No requiere instalación ni compilación.
